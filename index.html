The Method

A SYSTEM, NOT A
COLLECTION OF TRICKS.

Every experiment runs on the same four-step loop. The discipline isn't the framework — it's refusing to ship a test that hasn't passed all four gates.

01
01 / Research
Find the friction.

Heuristic analysis, heatmaps, session replay, qualitative review. The data tells me where users hesitate — recordings tell me why.

02
02 / Hypothesise
Problem to mechanism.

Every test gets a written hypothesis tying observed friction to a proposed mechanism. PIE scoring sets priority. If I can't articulate the why, it doesn't ship.

03
03 / Test
Controlled, instrumented.

VWO / Optimizely with data-layer integrity across GA4, GTM, Amplitude, Heap. No dirty splits, no eyeballed wins.

04
04 / Learn
Win or learn.

Significance review, behavioural read-out, written learning that updates the next test's prior. Losses are evidence, not waste.

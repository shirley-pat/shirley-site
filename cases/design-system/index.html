Case 02 · JustCall · Brand refresh and design system · 2026

A design system built from four years of test results, not taste.

Every past experiment told us something about how a page should be structured. We turned those learnings into components, set them on UX principles, and built 10+ page templates from them, so every page starts from what already converted.

01 · The problem

Every page was a one-off, so every win stayed on one page.

A test would prove something on the PPC pages, and the homepage, product pages and comparison pages would never get it. Each new page started from a blank canvas, looked a little different, and repeated mistakes we'd already paid for.

03 · 10+ templates, scaled across the site

A template for each page type, sized to its traffic.

Pages with a lot of traffic get the full set of folds, because there's enough volume to test every one. Low-traffic pages get a shorter template that keeps only the folds that have already proven themselves. Every fold comes with written rules: what it's for, how much copy it takes, and when it's mandatory.

How a fold is specified
Hero fold
Centre-aligned headline, full-width product screenshot. Mandatory on high-traffic pages.
How a fold is specified
Customer logos
Straight under the hero, no headline. The logos earn trust before the first scroll.
How a fold is specified
Social proof
Three stat cards and one quote, with word limits set for each.

04 · The brand layer on top

Three parts, each with one job.

Colour
Electric Blue is the global primary. Every accent has one role; anything not listed stays neutral.
Type
Aa
Instrument Sans on every marketing surface, two weights only. "Precise enough to trust. Friendly enough to talk to."
Morse pattern
J and C spelled in Morse, two rows on one centre axis. The last dot is Electric Blue. One tile, anchored bottom-right, never over copy, a CTA or the logo.
05 · Five principles the team designs by
Say it in one breath
Outcome up front, jargon out.
Show, don't tell
Real product on screen beats adjectives.
Quiet stage, one spotlight
Colour enters once, on purpose.
Earn every claim
Real customers, real numbers, cited.
Built to repeat
Shared components, not one-offs.
06 · The component library

85 Figma folds the templates are assembled from.

07 · Making it stick
The system lives inside Claude, as skills the team uses.

Template choice, component rules, brand checks and copy checks are written as Claude skills, so a designer or freelancer starts every page from what already converted. Every new page goes through them: pick the template, check the brand rules, check the copy, then hand off to build.

08 · What I chose not to change

The logo and the core brand colours. Buyers and customers already know them, so the system changed how pages are built, not how JustCall is recognised.

09 · What's next

Brand book 2.0 is still in progress: motion and illustration rules, and lining up the website components with the product UI so the site and the app feel like one brand.

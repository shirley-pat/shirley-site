Live · started from Slack

Stops requests and tasks from stalling in Slack.

GA4 BigQuery report library
Live · weekly, Mondays

Consistent, trustworthy numbers week to week.

CoversTraffic, demo funnel, signup funnel, landing groups, landing page performance, homepage, plus a daily mobile demo-form monitor.

Reuse it · dependencies
Reuse

Every skill downloads as a ZIP, and every agent, automation and data item has a written note. Some skills expect files from my local vault, and Warden and CRO Scraper code, the BigQuery SQL files and two skills live in private projects.

Dependencies

Slack, Google Sheets, Jira, Notion, BigQuery and Vercel, plus Manus and Grok for the research automations. There is no direct BigQuery connector: analysis uses exported CSVs. Unattended runs need team-owned runners, a service account, a shared Jira token and a shared Slack app.
